# Сторонние компоненты и лицензии

Состояние на 11.11.2026. Требование: ТЗ, дополнительный комплект передачи («описание используемых библиотек и лицензий»).

Сервер и сайт работают **без внешних библиотек**: в `package.json` нет зависимостей, `npm install` не нужен. Всё, что взято со стороны, перечислено ниже.

## Входит в репозиторий

| Компонент | Что это | Лицензия | Где |
|---|---|---|---|
| Шрифт Inter (Regular, SemiBold) | Основной шрифт интерфейса | SIL Open Font License 1.1 | `fonts/Inter-*.woff` |
| Шрифт Lora | Шрифт заголовков | SIL Open Font License 1.1 | `fonts/Lora.woff` |
| QRCode for JavaScript (Kazuhiko Arase) | Рисует QR-код в «Памятке посетителя» | MIT | встроена в `dev/src.html` (сборка выносит её в `qr.<хеш>.js`), в шапке библиотеки указан автор и лицензия |
| Логотип архива | Официальный логотип, предоставленный для проекта | права у архива | `img/logo.webp`, `icons/`, `docs/brand/` |
| Государственные символы Республики Казахстан и герб Усть-Каменогорска | Страница «Об архиве» | государственные символы; использование по правилам их применения | `img/symbols/`, `img/ust-kamenogorsk-arms.png` |
| Тексты, фотографии, документы, каталог | Содержание архива | права у архива и авторов, см. [TEST-DATA.md](TEST-DATA.md) | `pages/`, `img/`, `public-docs/`, `dev/*.json` |

Тексты лицензии SIL OFL 1.1 для шрифтов лежат у их авторов (rsms.me/inter, fonts.google.com/specimen/Lora). Шрифты в проекте не изменялись.

## Внешние сервисы (не входят в репозиторий)

Подробная таблица (владелец, доступ, что передаётся, ключи, тарифы, резервный сценарий, статус) — в [READINESS.md](READINESS.md), раздел 3.

## Только для разработки (в сайт не попадают)

| Компонент | Для чего | Лицензия |
|---|---|---|
| Node.js 20.6+ | Запуск сервера | MIT и лицензии составных частей |
| Python 3 (стандартная библиотека) | Сборка `dev/build.py` | PSF License |
| Playwright for Python | Проверки вёрстки и контраста `tests/layout.py`, `tests/contrast.py`, `tests/hero.py` | Apache License 2.0 |
| Pillow, NumPy и модели увеличения фото | Необязательные скрипты подготовки данных в `tools/` (в том числе `upscale.py`); модели (до 64 МБ) в репозиторий не входят, где их взять, написано в шапке скрипта | лицензии библиотек и моделей смотрите у их авторов |

## Как проверить

В репозитории нет папки `node_modules`, а `package.json` не содержит зависимостей. Список шрифтов: `ls fonts`. Библиотека QR: `grep -n "Kazuhiko Arase" dev/src.html`.

## Instagram (окошко с публикациями)

Иконка Instagram открывает окошко с последними публикациями @arhiv_vko. Это снимок публичной страницы (`pages/social.json`), превью лежат на нашем сервере (`img/ig-*.jpg`, взяты с публичной страницы 11.11.2026), поэтому сайт сам к Instagram не обращается. К instagram.com посетитель переходит только по ссылке: на публикацию или на профиль (новая вкладка); дальше действуют условия и политика конфиденциальности Instagram (Meta). Права на изображения принадлежат архиву как владельцу аккаунта.
